                                     Project Proposal: Student Helper Discord Bot

Project Description
Our project is to create a Discord bot that helps students by answering common academic questions and providing useful information. The bot will allow students to ask questions and receive quick responses directly through Discord.

Problem Statement
Students sometimes have questions about homework, studying, assignments, and school resources. It can take time to find the right information. This bot will make it easier for students to get answers and helpful information in one place. It could also be used by Brett if he notices a common problem that students are coming up against and wants to add some help. 

Proposed Solution 
We plan to develop a student helper discord bot using Python. Students will interact with the bot through discord commands.
The bot will include these features:
help - Shows students the available commands.
ask - Allows students to ask common questions and receive answers. (Common questions provided by the teacher, or by us depending on whether you had any Brett. Probably generalized at first but maybe based on specific assignments if we get the time.)
study - Provides useful study tips. (Taken from the internet or from personal experience in what helps us.)
homework - Provides tips for organizing homework and assignments.
﻿﻿And if we can we well add quote Shares motivational quotes for students if they are feeling depressed and unmotivated to complete the assignment 

Technical stack and tools 
Python
Discord

Discord API
GitHub

Knowledge and Skills
The project will use basic Python programming problem solving, and command line skills. We will also learn how to create Discord bots, use Discord.py, create commands, and connect the bot to a Discord server.
       The minimum working version will include:
A functioning Discord bot.

A help command.
Testing in a Discord server.
Additional features may be added after the basic version is working. I would be interested in adding a database of questions asked that we don’t have an answer to and reviewing that every so often to see if we can add answers to commonly asked questions we didn’t think of.
The final deliverables will include the source code GitHub repository documentation, testing, and a final presentation.
